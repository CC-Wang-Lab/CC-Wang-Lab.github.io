\begin{words}
This two-phase cooling test platform evaluates two-phase cold plates under controlled operating conditions. The working fluid circulates from the tank through the pump, preheater, flow meter, test section, and condenser before returning to the tank. The system controls the flow rate, pressure, and fluid temperature while recording steady-state thermal and hydraulic data. It is used to evaluate boiling curves, critical heat flux, heat transfer coefficients, thermal resistance, pressure drop, and flow behavior.

### Main Function

- Evaluate two-phase cold plates
- Control flow rate, pressure, and fluid temperature
- Record thermal and hydraulic data at steady state
- For various working fluids, up to 5 kW

### Flow Path

Tank → Pump →( Preheater)→ Flow meter → Test section→ Condenser → Tank

### Main Function

- Boiling curve / CHF
- Heat transfer coefficient (HTC)
- Thermal resistance
- Pressure drop
- Flow visualization
