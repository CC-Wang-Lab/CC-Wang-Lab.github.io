# Third-party licenses

Every claim below was checked against the actual `LICENSE` file of the project named, on
2026-08-20. Nothing here is from memory.

The site's own terms are in [LICENSE](LICENSE): **MIT for the machinery, all rights reserved for
the laboratory's content.**

## What is actually redistributed

Only one thing: the **ET Book** font files under `_assets/et-book/`. The MIT licence requires the
copyright notice to travel with the copies, so it is repeated in two places:

| Where | Reaches |
|---|---|
| `_assets/et-book/LICENSE` | **the deployed site**, at `/assets/et-book/LICENSE`, beside the fonts it covers |
| This file | anyone who clones the repository |

*Why both: `_assets/` is copied verbatim into `__site/`, but this file is in the `ignore` list in
`config.md` and never deploys. A visitor downloading the .woff would otherwise get the font with
no notice attached.*

Everything else is loaded from a CDN, or is a build tool that never reaches a visitor. Neither
redistributes anything, so neither carries a notice obligation.

| What | Where it comes from | License | Verified against | Redistributed? |
|---|---|---|---|---|
| **ET Book** (the serif) | `_assets/et-book/` | MIT, © 2015 Dmitry Krasny, Bonnie Scranton, Edward Tufte | `edwardtufte/et-book` `LICENSE` | **Yes** |
| Bootstrap 5.3 | jsDelivr CDN | MIT, © 2011–2026 The Bootstrap Authors | `twbs/bootstrap` `LICENSE` | No |
| Bootstrap Icons 1.11 | jsDelivr CDN | MIT, © 2019–2024 The Bootstrap Authors | `twbs/icons` `LICENSE` | No |
| Noto Serif TC | Google Fonts | SIL Open Font License 1.1 | `notofonts/noto-cjk` `Serif/LICENSE` | No |
| Franklin.jl | build tool | MIT, © 2018–2022 Thibaut Lienart | `JuliaDocs/Franklin.jl` `LICENSE.md` | No |
| OpenStreetMap map embed | openstreetmap.org iframe | ODbL, © OpenStreetMap contributors | attribution rendered by the embed itself | No |

**The OpenStreetMap credit was checked on screen, not assumed.** The embed draws
"© OpenStreetMap contributors" in the bottom-right corner of the iframe on `/contact/`. That is
the attribution ODbL asks for. If the map is ever replaced with self-hosted tiles, the credit has
to be drawn by this site instead.

## FranklinTemplates.jl — nothing of it is here

Worth writing down, because the question is a reasonable one to ask.

The Franklin template gallery footer reads
*"CC BY-SA 4.0 Septimia Zenobia. Last modified: … Website built with Franklin.jl …"*. That line is
**placeholder demo text**, not a licence on the template:

- it is hard-coded in `src/templates/common/_layout/page_foot.html` in FranklinTemplates.jl;
- `Septimia Zenobia` is the placeholder `author` in `src/templates/common/config.md`;
- **FranklinTemplates.jl itself is MIT**, © Thibaut Lienart 2018–2021.

So the CC BY-SA applies to the demo site's own sample words, and it is meant to be replaced.

**This site never carried it.** `_layout/page_foot.html` here is deliberately empty and the footer
is generated by `hfun_footer` in `utils.jl`. There is no CC BY-SA string anywhere in the source,
and no share-alike obligation attaches to anything on this site.

Nor is anything else left from the template: `_css/style.css` was written for this laboratory,
`utils.jl` contains none of the template's default functions, the template's KaTeX and highlight
stubs were removed, the favicon set was regenerated from the laboratory's own logo, and
FranklinTemplates.jl is not in `Project.toml`.

## Partner logos

Fifteen organisation logos ship under `_assets/img/partners/`. They are not a licensing question
and they are not listed above, because no copyright subsists in them — they are simple wordmarks
below the threshold of originality, taken from Wikimedia Commons as public domain.

**Trademark is the live question, not copyright**, and it is answered by how they are used.
`_assets/img/partners/SOURCES.md` records the source and the copyright status of every file, and
the reasoning behind the heading "Organizations we have worked with".
