# Logo files still needed

**15 of 59 organizations have a logo. These 44 do not**, and render as
their name in text until a file arrives. The strip works either way, so nothing is blocked.

## How to add one

1. Put the file in this folder as `<file>.svg` from the table below. SVG is preferred; a PNG with a
   transparent background is fine. Aim for a wide, horizontal version of the mark.
2. In `_data/partners.toml`, find that organization and set its `logo`:

   ```toml
   logo    = "/assets/img/partners/sunon.svg"
   ```

3. Rebuild. That is all — nothing else references the file.

**Keep each file under about 40 KB.** One of the existing files, `cpc.svg`, is 106 KB because it
carries a detailed emblem; that is the upper limit worth accepting.

## Where to look

In order of how well it usually works:

1. **The lab's own collage slide.** It already holds every one of these in the approved set. This is
   by far the fastest route and it has not been supplied yet.
2. **The company's own press or brand page.** Most Taiwanese listed companies publish one.
3. **Wikimedia Commons.** Where the 15 existing files came from. It carries the large international
   names and almost none of the smaller Taiwanese firms.

**Look at every file before accepting it.** Searching for these by name is unreliable: a search for
"ASE Group logo" returned the European Space Agency banner, "Lite-On logo" returned an unrelated
mark reading "TL", and "Google logo" returned the Google Play logo from 2012. All three were caught
by looking, and all three would have been visible errors on a public page.
